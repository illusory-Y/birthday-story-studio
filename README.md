# Birthday Story Studio

面向儿童生日的本地优先短视频创作工具。照片、视频、字幕和项目数据默认只保存在当前设备，不需要后端账号，也不会上传到云端。

## 当前功能

- 9:16 竖屏短视频创作工作区，包含素材区、字幕编辑、场景时间线和全屏剧场。
- 支持从本机加入图片和视频素材，并绑定到不同成长回忆场景。
- 动态字幕和浏览器本地朗读，文字可以直接成为画面叙事的一部分。
- Three.js 实时 3D 舞台：蛋糕层、奶油、蜡烛、火焰、灯光和空间烟花。
- 六种儿童主题世界，可切换颜色、背景和 3D 舞台氛围。
- IndexedDB 本地素材保存，以及 .birthday 项目备份导入/导出。
- PWA 离线基础能力，适合部署到 GitHub Pages，也可以在手机浏览器中打开。

## 本地运行

    npm install
    npm run dev

## 构建与发布

    npm run build

生产文件输出到 dist/。GitHub Pages 当前从 main 分支的 docs/ 目录发布；构建后将 dist/ 内容同步到 docs/ 再提交即可。

## 隐私说明

本项目没有上传接口。用户选择的图片和视频只进入浏览器 IndexedDB，并通过本地对象 URL 在预览中播放。公开仓库和 GitHub Pages 不应放入儿童真实照片。
